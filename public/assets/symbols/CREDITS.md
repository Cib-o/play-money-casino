# Symbol artwork

Every reel symbol in this directory comes from one open-licensed pack.
Nothing here is derived from a commercial slot vendor.

## Gem Match Three

- **Author:** Andrew Tidey (`Sylly` on OpenGameArt)
- **Source:** https://opengameart.org/content/gem-match-3-set
- **Licence:** [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
  (public domain dedication — free for personal and commercial use,
  attribution not required)
- **Files:** all 24 `gem-*.png`, taken from the pack's `PNG/Large`
  directory and renamed `gem-<shape>-<colour>.png`. The images are
  otherwise unmodified.

The pack ships four shapes in six colours. This project reads the shape
as the pay tier — squares are the common low symbols, octagons are mid,
diamonds are high, triangles carry the wild and scatter — so a player
can tell roughly what a symbol is worth without reading the paytable.

Attribution is not required by CC0, but the author asked to be credited
if it is convenient, and it is.

## Wild and scatter badges

The "WILD" and "SCATTER" treatments are not separate images. They are
CSS drawn over a gem in `public/css/slots.css`, so they inherit each
cabinet's palette and stay crisp at any size.
